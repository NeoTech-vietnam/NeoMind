# Memory

Bounded hub for facts needed across the project. Read `RULES.md` first. Load a detail file only when the task needs it.
Session history, tracker history and Git are supporting evidence, not memory.

**One fact, one owner file.** Write each durable fact once, in the file that owns it. Here, point to that file.
Do not copy source documents, analysis chains, session IDs, to-do graphs or build diaries into this hub.
