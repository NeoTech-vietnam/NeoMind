# WorkForce native candidate — 10 November 2026

Candidate: runtime `0.3.0-alpha.1`, VSIX `0.13.0`, URL Agent Plugin `0.2.0-alpha.1`. Branch: `codex/workforce-vscode-native`. **Not released or fully accepted.** The published release remains separate from this candidate.

## Implemented boundaries

- Production extension activates native Local tools, read-only V-model, capabilities, optional Focus Space and optional managed model/MCP providers. It does not activate the historical controller or open a catalog/engine connection.
- Public CLI/MCP entry is native for both new projects and existing saved Local configurations. MCP exposes status and advisory experience; product dispatch requires the actual editor invocation context. Historical IDs/config/records remain readable and are not rewritten to claim completion.
- New CLI installations select `vscode-native` and do not create a legacy routing-alias policy. Generated profiles inherit native models. Existing routing files remain history/configuration for their original contracts.
- Full pinned local Agent Plugin packages use documented native workspace registration. Deferred controls protect owned resources; they do not claim control of arbitrary external native server/cache operations.
- Optional managed 9router is pinned to `0.5.116`, with exact published archive and license. It is materialized offline and uses private state/SecretStorage. No accounts or tokens are copied from other extensions. Catalog declarations are distinguished from connected routes and verified inference.
