# NeoMind alpha.4 and VS Code Agent Monitor 0.4.0

This prerelease pairs the NeoMind CLI/MCP/runtime with the installable VS Code extension. Download both packages from the same release and follow [installation](../install-release.md).

## Included

- Nine Copilot expert profiles: Coordinator, Explorer, Researcher, Planner, Architect, Implementer, Debugger, Verifier and Reviewer, mapped to twelve stable core role policies.
- A textured, animated agent universe with task moons, recorded relationships, an activity inspector and guarded per-role 9router controls.
- Earth FocusSpace with a reversible zoom, persistent countdown, read-only calendar feeds/ICS imports and focus-window suggestions, current-location/city weather, three original ambient soundscapes, and explicit YouTube video/playlist loading with optional API search.
- Local installation rules in `.git/info/exclude` that preserve prior exclusions and leave project `.gitignore` untouched.
- Cornell creation compatibility for unused blank/null optional revision fields, with required IDs, stale-revision checks and ownership gates preserved.

## Verification and limits

Release assets include test/packaging validation and SHA-256 digests. Automated protocol and isolated provider tests do not establish live model inference, personal calendar access, or playback inside every VS Code webview. Saved universe trails remain historical relationships; the current reported-activity channel requires updated profiles and does not intercept arbitrary existing Copilot chats. Calendar suggestions depend on the supplied feed and are not reservations. YouTube may require the browser fallback when embedding is blocked.

This release does not include the subsequent request for full Codex expert-profile parity, new activity synchronization, revised Cornell generation/publication, new validation skills, or scheduled REA/upstream adoption. Those changes are held for separate development.

The release is distributed through GitHub as a runtime `.tgz` and VS Code `.vsix`. It is not an npm-registry or VS Code Marketplace publication. Installation preserves project records and existing model/provider configuration; reload VS Code and restart the NeoMind MCP server after upgrading.
