# Bàn giao chạy lại flow và OpenCode — 08/11/2026

- Run `blocked` có flow và yêu cầu được lưu hiển thị nút **Chạy lại từ đầu**. Nút mở form tạo run với prompt và flow cũ, preview lại theo cấu hình hiện tại; không sửa run cũ, không tự duyệt, không tự sao chép override. Build core và UI đạt; test rerun đạt 1/1 trên Windows.
- OpenCode chưa là runner được hỗ trợ. Transport thử nghiệm trong `src/adapters/opencode-server.ts` khởi động server trong scope được cấp, dùng Basic auth và cấu hình cô lập; hai test dùng server giả đạt. Không đăng ký transport thành runner hoặc tuyên bố sandbox đã được xác minh.
- Probe OpenCode 1.18.25 với provider giả: `--pure` không ngăn MCP trong cấu hình project, và permission theo agent có thể thắng deny toàn cục. Thử thêm `OPENCODE_DISABLE_PROJECT_CONFIG=1`, `OPENCODE_DISABLE_EXTERNAL_SKILLS=1` và XDG riêng thì MCP project không chạy, tool model nhận chỉ gồm read/glob/grep. Chưa chứng minh phiên bản khác, chưa inference thật. API server có thể xác nhận model/session và JSON schema nhưng chưa tích hợp toàn bộ.
- Probe đối kháng trong Git fixture trên Windows: quyền `edit` chỉ cho `allowed/*`, `external_directory: deny`, nhưng `allowed/link` là junction trỏ ra ngoài repo; tool write báo thành công và tạo file ngoài repo. Không coi permission engine của OpenCode 1.18.25 là bằng chứng giới hạn phạm vi ghi; cần cơ chế bảo vệ hoặc từ chối an toàn và probe lại trước khi bật runner.
- Việc còn lại cho runner: lưu và khôi phục ánh xạ session an toàn; xác minh model, quyền, output, credentials và stop; session server cần tuân thủ thứ tự ghi scope trước khi chạy. Admission yêu cầu chứng minh cách ly với runner ngoài Codex: Claude đạt `sandboxVerified` qua probe cơ chế quyền, không phải sandbox hệ điều hành. OpenCode vẫn cần chứng minh tương đương; không khẳng định cách ly khi thiếu bằng chứng.

Các lỗi quan sát được gồm nhóm khóa file, reviewer song song, profile và program trong sandbox; output tổng kết bị cắt nên không ghi số lượng. Chưa kết luận nguyên nhân.
