Mục tiêu
calc.js có hàm power(a, b) trả về a mũ b, được export cùng add; calc.test.js kiểm tra số mũ dương, số mũ 0 và cơ số âm.
Cách làm
  1. Trong calc.js, thêm function power(a, b) { return Math.pow(a, b); } ngay sau add.
  2. Sửa export thành module.exports = { add, power };, giữ nguyên add.
  3. Trong calc.test.js, thêm 2 assertion: power(2, 3) === 8, power(5, 0) === 1.
  4. Trong calc.test.js, thêm 3 assertion: power(2, 3) === 8, power(5, 0) === 1, power(-2, 3) === -8.bản 2
  5. Chạy npm test để xác nhận.
