Lessons đề xuất ĐỀ XUẤT

1 lesson · chưa lưu

Chỉ bản bạn duyệt mới được đưa vào memory dùng chung của project. Agent sẽ đọc nó ở các run sau.

Khi thêm hàm vào calc.js, giữ export dạng object module.exports = { add, … } và thêm assertion qua calc.<tên hàm> trước dòng console.log cuối của test.js. Quy ước code

Lý do: test.js import cả module (const calc = require('./calc')) và dòng console.log cuối là dấu hiệu mọi assertion đã chạy. Đặt assertion sau dòng đó làm thông báo 'all tests passed' sai lệch.

Ghi chú thiết kế

  1. Primary duy nhất là "Áp dụng vào branch main". Lệnh git thủ công giữ nguyên, chuyển thành lựa chọn phụ.
  2. Nếu checkout có thay đổi chưa commit hoặc đang ở branch khác, nút bị khóa kèm lý do (ví dụ "Checkout có 2 file chưa commit").
  3. Màn thật hiện thẻ "Kế hoạch đã duyệt" đầy đủ; mockup thu gọn để tập trung vào phần Kết quả.
