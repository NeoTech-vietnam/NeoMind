Vấn đề ở bản hiện tại → cách bản đề xuất xử lý

1Bốn hàng điều khiển trước nội dung. → Còn header 2 dòng + một hàng tab.
2Ba kiểu nút chọn khác nhau (viên cam, khối xám, viền cam tràn). → Lượt là menu nhỏ cạnh tiêu đề; nguồn ghi vào menu "…"; lọc là tab chữ có số đếm, tab bằng 0 làm mờ.
3Thống kê bằng font code in đậm + emoji. → Dòng phụ chữ thường, màu nhạt.
4Đầu vào/đầu ra nặng ngang "Đọc .gitignore". → Thành thẻ có xem trước; kế hoạch hiện theo trường thay vì JSON.
5Ba thứ có viền trên mỗi dòng, icon Unicode khó hiểu. → Icon nét một màu, tên file mono không đóng khung, đường dọc nối timeline.
6Màu icon trùng màu trạng thái. → Icon xám; chỉ "Xong" xanh lá, lỗi đỏ, đang chạy xanh dương.
7Lề trái lệch, token lặp lại ở dòng cuối. → Lưới 3 cột cố định; dòng cuối tóm tắt cả lượt.
8Bảy dòng "Đọc" liên tiếp, giờ bên phải bị cắt. → Gộp "Đọc 7 file"; giờ tương đối (+0:07) trong cột cố định, giờ đầy đủ khi rê chuột.
9Tiêu đề là id thô "Plan", không thấy kết quả. → "Lập kế hoạch" + badge trạng thái của lượt.

Dữ liệu mẫu (nội dung prompt, kế hoạch, số file tìm thấy, giờ) là minh họa; cấu trúc lấy từ ảnh chụp thật. Font đề xuất Be Vietnam Pro / JetBrains Mono; nếu máy chưa cài, mockup dùng Segoe UI / Cascadia Mono.
