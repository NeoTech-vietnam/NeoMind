Thay đổi so với shell hiện tại:
  1. Trong Nimbalyst, panel từng render nguyên topbar 58px + sidebar 232px: hai logo, hai điều hướng, mất ~25% bề ngang. Giờ chỉ còn thanh tab 40px (bấm “Panel Nimbalyst”).
  2. Panel luôn tối dù Nimbalyst dùng theme sáng. Giờ theo theme của host; bản web có công tắc sáng/tối.
  3. Runs lên đầu và là màn mặc định; số hổ phách là run cần bạn. Clay chỉ còn ở logo, mục đang chọn là nền xám.
  4. Nhãn tiếng Việt, đường dẫn project rút gọn (đầy đủ khi rê chuột). Ctrl K tìm flow, run, lệnh ở cả hai shell.
