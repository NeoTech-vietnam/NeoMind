NeoMind · Design system

Nền chung cho mọi màn của Flow Studio: màu, chữ, component và quy ước. Các mockup khác dùng đúng khối CSS NEOMIND SHARED STYLES ở đầu file này. Phần nào chưa có trong code được đánh dấu ĐỀ XUẤT.

Nguyên tắc

  • Người dùng ra quyết định, agent làm việc. Màn nào cũng phải trả lời: run đang ở đâu, tôi cần làm gì, kết quả nằm ở đâu.
  • Trạng thái bằng màu và chữ, không chỉ bằng icon. Mỗi trạng thái có một tone cố định (bảng dưới) và nhãn tiếng Việt.
  • Thứ quan trọng lên trước, kỹ thuật vào "Nâng cao". Runner/model, kế hoạch, kết quả lên đầu; session group, binding id, JSON để trong mục thu gọn.
  • Không trang trí vô nghĩa. Mỗi phần tử phải bấm được hoặc cho biết điều gì đó.
  • Chữ đọc được: nội dung 14px, phụ 12.5px, không dưới 11px.

Màu · dark, theo tông Claude Code

Nền than ấm, chữ trắng ngà, màu nhấn clay của Claude. Đánh dấu ĐỀ XUẤT dùng xanh teal để không lẫn với màu nhấn.
